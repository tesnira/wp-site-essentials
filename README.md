# WP Site Essentials

一个轻量、独立的 WordPress 站点基础插件，提供 URL 小写重定向、敏感 REST 接口隐身、全局禁用评论，以及站点清理工具。

## 基本信息

- 作者：`biancaplus`
- 当前版本：`1.0.0`
- WordPress：`6.0+`
- PHP：`7.4+`
- 许可证：[GPL-2.0-or-later](https://www.gnu.org/licenses/gpl-2.0.html)
- 页面构建器：无依赖

## 功能

- 前台大写 URL 路径 301 重定向为小写（保留 query，跳过静态资源与核心目录）。
- 对未登录用户隐藏可配置的敏感 REST 路由（预置多选 + 自定义路由）。
- 全局关闭评论与 trackback：拦截评论提交、隐藏后台入口、屏蔽评论 REST 与 pingback。
- 站点清理工具：修订（每篇保留 3 个）、自动草稿、回收站、垃圾评论、过期 transient、孤立 meta。
- 自动识别本站文章类型：内置、已注册自定义 CPT、数据库中仍有内容的未注册类型，均可勾选清理。
- 清理工具支持按本次勾选的文章类型执行（历史版本 / 自动草稿 / 回收站）。
- 各策略功能默认关闭（安全默认）；卸载时可选择是否删除设置数据。

## 安装

1. 将 `wp-site-essentials` 目录上传至 `/wp-content/plugins/`。
2. 在 WordPress 后台的「插件」页面启用 **WP Site Essentials**。
3. 前往「设置 > 站点基础」按需开启各模块并保存。

启用插件后默认不会改变站点既有行为。

## 设置说明

路径：`设置 > 站点基础`

| 分组 | 说明 |
|------|------|
| URL 规范 | 开关：大写 path → 小写 301 |
| 敏感 REST | 模块开关 + 预置路由多选 + 自定义路由（每行一条） |
| 全局禁评 | 一键关闭评论相关能力 |
| 站点清理 | 单页勾选文章类型与清理项；可「保存为默认勾选」 |
| 卸载 | 可选「卸载时删除数据」（默认关） |

## 卸载

默认卸载**不会**删除设置。

仅在勾选「卸载插件时删除本插件的全部设置数据」后，卸载才会清除 `wpse_settings`。

## 常见问题

### 启用插件后站点行为有变化吗？

默认没有。需在「站点基础」中打开对应开关并保存。

### 敏感 REST 会影响后台编辑吗？

不会。已登录用户仍可访问完整 REST 端点；仅未登录访客看不到勾选的路由。

### 自定义 REST 路由写错会怎样？

保存时会校验格式；非法行会被忽略，并在页面提示。

### 清理工具会删掉所有修订吗？

不会。历史版本清理会为每篇文章保留最新 3 个修订。
